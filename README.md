# DevOps Voting App

A production-grade 3-tier voting application built to learn DevOps practices.

## Architecture
- **Frontend**: React
- **Backend**: Node.js API
- **Database**: PostgreSQL

## DevOps Stack
- CI/CD: GitHub Actions
- Containers: Docker
- Orchestration: Kubernetes + Helm
- IaC: Terraform
- Monitoring: Prometheus + Grafana
- GitOps: ArgoCD
